# AGENTS.md

## Project Overview

This project is an AI-assisted survey platform for social science research. The platform supports survey creation, flow control, AI conversations, and response collection.

## General Guidelines

- Follow the existing project structure and specifications.
- Keep changes simple and consistent with the current implementation.
- Do not modify database schemas without explicit instructions.
- Do not expose API keys, passwords, or sensitive user data.
- Keep AI interactions neutral, respectful, and appropriate for research purposes.
- Do not make unnecessary changes to unrelated modules.
- Ask for clarification when requirements are unclear.

## Development Guidelines

- Follow the existing PRDs.
- Preserve existing functionality unless changes are explicitly requested.
- Validate inputs and handle errors appropriately.
- Test affected functionality before completing changes.
